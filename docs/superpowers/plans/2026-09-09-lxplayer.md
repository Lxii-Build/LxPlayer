# LxPlayer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship LxPlayer — an Android Compose music player (Cyrene visual language, Hyacine home-card swipe, NeriPlayer-style playback) plus a Go backend that only stores accounts and user data — with a GitHub Actions workflow that produces identically-signed debug and release APKs and stays green.

**Architecture:** Single-module Android app (`cc.lxii.player`) talks to a Go+SQLite server over JWT. Playback is a `MediaSessionService` wrapping one ExoPlayer; URL resolution happens before `setMediaItem` behind a monotonic token. Queue math, swipe thresholds, wake-mode, sleep timer and sync merge are pure functions with JVM tests. CI, not the local machine, is the build environment.

**Tech Stack:** Kotlin 2.4.10, Compose BOM 2026.06.01, Media3 1.10.1, Room 2.8.4, DataStore 1.2.1, Coil 3.0.4, OkHttp 4.12.0, AGP 9.3.1, Gradle 9.7.0, JDK 21, compile/target/min SDK 36/36/28. Backend: Go 1.23, `net/http`, SQLite, bcrypt, HS256 JWT.

**Spec:** `docs/superpowers/specs/2026-09-09-lxplayer-design.md`

## Global Constraints

- applicationId / namespace: `cc.lxii.player`; app label: `LxPlayer`; no leftover Hyacine / Cyrene / NeriPlayer / LxDay branding in user-facing strings.
- Do not copy NeriPlayer source (GPL-3.0). Reimplement from the spec.
- Do not proxy, store, or resolve audio on the server.
- First-version `MusicSource` implementation is local MediaStore only.
- Home card is NOT a `HorizontalPager`. Gesture thresholds: activate 12dp, fail-vertical 24dp, commit 36dp; 260ms enter animation; fanned covers at the exact sizes/offsets/alphas/rotations in the spec.
- Debug and release APKs MUST share one signing certificate. CI extracts both SHA-256 fingerprints and fails the job if they differ.
- Do not run `./gradlew assemble*` on the developer machine. Verification happens on GitHub Actions (`Lxii-Build/LxPlayer`).
- APK contains no shared secrets; tokens live in Keystore AES/GCM.
- JWT algorithm is HS256 only; `token_ver` invalidates all sessions on password change.
- `enableV1Signing = false`; v2/v3/v4 = true.

QueuePolicy tests:
```kotlin
@Test fun insertNext_dedupesAndShiftsIndexWhenExistingIsBeforeInsertPoint() {
    val a = track("a"); val b = track("b"); val c = track("c")
    val result = QueuePolicy.insertNext(listOf(a, c, b), currentIndex = 0, track = c)
    assertEquals(listOf(a, c, b), result.queue) // c moved to next
    assertEquals(0, result.currentIndex)
    assertEquals("c", result.queue[1].id)
}

@Test fun insertNext_onEmptyQueueStartsPlayback() {
    val a = track("a")
    val result = QueuePolicy.insertNext(emptyList(), currentIndex = -1, track = a)
    assertEquals(listOf(a), result.queue)
    assertEquals(0, result.currentIndex)
}

@Test fun removeCurrent_advancesToWhatWasNext() {
    val result = QueuePolicy.remove(listOf(track("a"), track("b"), track("c")), currentIndex = 1, removeIndex = 1)
    assertEquals(listOf(track("a"), track("c")), result.queue)
    assertEquals(1, result.currentIndex)
}

@Test fun shuffle_thenRestore_returnsOriginalOrderAndIndex() {
    val original = listOf(track("a"), track("b"), track("c"), track("d"))
    val shuffled = QueuePolicy.shuffled(original, currentIndex = 2, seed = 7L)
    val restored = QueuePolicy.restore(shuffled)
    assertEquals(original.map { it.id }, restored.queue.map { it.id })
    assertEquals(2, restored.currentIndex)
}
```
